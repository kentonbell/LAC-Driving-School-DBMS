# LAC-Driving-School-DBMS
An AI integrated database management system. Our stack uses React, TypeScript, and Vite, with Tailwind CSS and shadcn/ui, with an installable PWA hosted on Cloudflare Pages. A Cloudflare Worker API handles booking, SQL reports, and AI requests, backed by PostgreSQL on Neon.

The first database draft, sample data, reports, ER diagram, and setup instructions
are in [database/README.md](database/README.md).
